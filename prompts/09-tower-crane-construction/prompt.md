# Tower crane — one-shot prompt

Source: [@HarshithLucky3 on X](https://x.com/HarshithLucky3/status/2082162301185180048)

```
3D simulation of autonomous tower crane erecting a full 8 storey steel building in three js
```

## Why this works as a prompt class

Short domain-specific simulation prompts with:

1. **Agent** (autonomous tower crane)
2. **Process** (erecting)
3. **Concrete deliverable** (full 8-storey steel building)
4. **Stack** (Three.js)

…tend to produce coherent multi-minute sequences better than vague "cool construction scene" asks.

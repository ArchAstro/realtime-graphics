Overview

Why it's here. Weird premise executed as a complete game (stations, grading, lore, synth score) in one HTML file with real PBR, UV-correct world-space tools, and GPU mask state. Shows short max-effort prompts can still yield deep systems if the model is strong enough.

Prompt

SOLEBOUND — original prompt

Source: @winchxyz on X

Create me a fully playable release-ready game. On GPU. Game about shoes repair simulator. Make it with maximum effort, show me best what you can create. Use all your power, knowledge and make best graphics and best game design. Surprise me with graphics, lore and everything.

What shipped (from README)

  • Parametric shoe geometry, Cook-Torrance + clearcoat, SSAO, bloom, ACES
  • Repair state on GPU masks (dirt/damage/polish/dye/stitch)
  • World-space tool interaction (not UV-smeared)
  • Full synth audio, 12 jobs, upgrades, endings

Swept-mesh wake / ribbon

A coherent body of snow or water is a mesh extruded along a path spine — not a particle blob.

SNOWFLOW surf + spells data texture · VS

How it works

  1. Record the path as samples (here: CPU array; production: 96×3 data texture).
  2. Build a static lattice of verts with attributes (column, row, side).
  3. In the VS, place each vert from spine position + normal/binormal × cross-section.
  4. curl bends the profile from a bank into a breaking lip.
P(s,t) = spine(s) + R(s) · profile(t, curl)

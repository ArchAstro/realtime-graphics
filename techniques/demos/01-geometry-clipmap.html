Geometry clipmap

Nested rings of terrain centered on the camera: dense near, sparse far — one mesh, one draw, displacement in the vertex shader.

SNOWFLOW · desert WebGL · Three.js

How it works

Instead of one huge heightmapped plane, you build concentric rings (or one mesh with a ring-level attribute). Ring 0 has ~fine spacing; each outer ring doubles the world extent covered per vertex.

  • Vertex attributes: gridIndex, ringLevel only
  • VS places the vertex in world XZ from those indices + camera center
  • Height sampled from a noise / height texture in the VS
  • Optional CDLOD morph blends the seam between rings
cost ≈ O(ringVerts) draws: 1 · no CPU rebuild

Why it matches the demos

SNOWFLOW ships 8 rings, 8.5 cm inner spacing, ~870 m radius, 333k tris — one static mesh. The desert explorer uses the same idea with Three.js TSL.

Persistent deformation buffer

Click/drag to dig. Depression + displaced mass (berms). Slow refill. This is the shared state feet and spells write into.

SNOWFLOW §2.3 RTT · ping-pong

How it works

  • R channel — depression depth
  • G channel — displaced mass (berms)
  • Brush splat each frame while interacting
  • Diffusion + decay pass softens trails over time
  • Vertex displacement samples R−G so trenches go down and berms up
h' = h₀ − depression + mass · bermScale

Production demos use a toroidal window that scrolls with the player (uv = fract(worldXZ / size)) so you never copy the whole buffer.

Wrapped diffuse + cheap SSS

Lambert dies at the terminator. Snow and skin need light that wraps and scatters through the edge.

SNOWFLOW snow SSS shading model

How it works

// wrap: softens N·L terminator
float wrap = (dot(N,L) + w) / (1.0 + w);
wrap = max(wrap, 0.0);

// back-scatter: light from behind bleeds through
float back = pow(saturate(dot(V, -L)), k) * scatter;
col += albedo * wrap * lightColor;
col += sssColor * back * thicknessApprox;

Production snow also tints the scatter blue-white and deepens it with path thickness / compression state. Dynamic spell lights should share the same include.

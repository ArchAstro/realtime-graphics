SDF blend-shell

Primitive meshes snapped onto a smooth-min SDF surface so overlaps become one seamless body — mesh cost, SDF look.

Fable creatures vertex SDF

How it works

  1. Author body as spheres or capsules (ordinary meshes).
  2. In the VS, evaluate smoothMin of all primitive SDFs at the vertex.
  3. Project the vertex onto the blended surface (along gradient).
  4. Normals from the SDF gradient → continuous lighting across joints.
float d = smin(d1, d2, k);
// Newton-ish project onto d=0
p -= normalize(grad) * d;

Still one (or few) mesh draws — no per-pixel raymarch. Mobile-friendly.

This sketch blends eight sdSphere primitives. Swapping in sdCapsule (a segment plus a radius) changes nothing structurally — the same smin, projection, and gradient-normal steps apply to any primitive that reports a signed distance.

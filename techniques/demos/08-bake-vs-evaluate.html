Bake vs evaluate

Twenty octaves of noise per pixel is a tax. Bake once, sample forever (or re-bake when the view changes).

Long Silence planets offline → runtime

How it works

  • Evaluate: fBm in the fragment shader every frame — flexible, expensive
  • Bake: render the field into a texture (or cubemap faces) once; runtime does a few taps + lighting
  • Planets: cubemap beats equirect (no poles/seams)
  • Normals from height via finite differences on the bake, not more noise octaves
cost_eval ∝ pixels × octaves · cost_bake = O(once) + O(taps)

Procedural PBR texture forge

Zero art files: noise → albedo / roughness / height → normals. Same idea as Claude of Duty’s material forge and Solebound’s leather.

Claude of Duty · Solebound noise → maps

How it works

height = pfbm(uv * scale, scale)  // period == scale
albedo = palette(height, dirt, wear)
rough  = mix(0.9, 0.3, height)
normal = sobel(height)  // or analytic ∂h
  • Periodic noise is not optional here: uv.x wraps at the sphere’s seam, so non-tiling noise draws a visible stripe pole to pole
  • Tiling needs three things together — an integer period, lacunarity of exactly 2.0, and the period doubled per octave. The usual p * 2.05 + offset octave trick silently breaks all three
  • Triplanar for steep / world-space surfaces
  • Curvature / height edges → wear and edge darkening
